CAB-02

How lengths are worked out

Pull length = ( conduit + casing route + start drop + mark-2 drop + end drop ) × 1.1, rounded up to the next metre

PartAllowance
RouteMeasured on the plan: cabinet → ceiling conduit → mark 2, then along the wall casing to the junction nearest the device and along the branch. IT Room runs follow the IT Room walls.
Start drop1.5 m from the cabinet up to the conduit (or down to the IT Room casing), incl. dressing loop
Mark-2 drop2.8 m from the ceiling down behind the wall to skirting (cabinet runs), or back up for AP2
End drop0.5 m at a desk surface box · 3 m up the wall to AP1 · 0.6 m at AP2 in the ceiling · 1 m when the far end is a switch
Slack10 % for following the walls around obstacles and termination
The longest run is C-09 (PC 6) at 25 m, well inside the 90 m Cat6 limit. Measure the real route on site before cutting; this table is for ordering and checking.
