INITIALISING OBSERVATION MATRIX
Distances and sizes are visually compressed so the entire cosmos fits one continuous zoom. Every object carries a status label — OBSERVED · MODELLED · THEORETICAL · HYPOTHETICAL · FICTIONAL · UNKNOWN. Sci-Fi content is never presented as real.

SYSTEM SETTINGS

Particle density changes and a new seed rebuild the universe (page reloads). The seed reshapes procedural fields, uncharted systems, fictional civilizations, UFO placement and anomalies. Real astronomical objects never move.
