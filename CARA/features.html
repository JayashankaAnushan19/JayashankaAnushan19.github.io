15 Integrated Features

CARA integrates 15 capabilities across three priority tiers. Critical features are evaluated first and are non-negotiable for the thesis; high and medium priority features are implemented where hardware and time allow.

Priority tiers: Critical — core safety High — strongly required Medium — desired if time allows

Critical Priority

These features are the core purpose of CARA. Without them, the fundamental research objectives cannot be met. They are implemented and tested first.

🤸
Critical

AI Fall Detection

MediaPipe Pose Estimation running on NVIDIA Jetson Nano at 12–15 fps. Monitors 33 body landmarks; triggers on hip-below-threshold + shoulder-low posture sustained for 2 seconds to eliminate false positives from bending or sitting.

📱
Critical

GSM Fall Alert SMS

Confirmed fall event triggers SIM800L GSM module to send SMS to registered family members within 30 seconds. Uses AT command set over SoftwareSerial — no internet required. Includes 30-second cooldown to prevent SMS flooding.

🚗
Critical

Obstacle Avoidance Navigation

12 × HC-SR04 ultrasonic sensors provide 360° coverage. Emergency stop at 20 cm threshold — non-overridable even during remote drive commands. The fundamental safety invariant of the platform.

👤
Critical

Person Following

Two-layer identity lock: RFID UID confirmation at session start (Layer 1) + continuous HSV orange-band wristband tracking via OpenCV (Layer 2). Publishes TARGET_LOST and returns to IDLE if band absent for 10 seconds.

💊
Critical

Medication Reminders

DS3231 RTC triggers audible buzzer + LCD message at 08:00, 13:00, 18:00, and 22:00 daily. User confirms by tapping RFID tag to reader. No button presses required — the RFID is embedded in the medication box lid.

⚠️
Critical

Missed-Dose SMS Alert

If medication RFID confirmation is not received within 15 minutes of a reminder trigger, the Arduino automatically calls the GSM SMS function to alert registered family members.

High Priority

These features significantly extend CARA's usefulness and are planned for full implementation alongside the critical tier.

📷
High

Live Camera Feed (Phone Browser)

Flask MJPEG streaming server runs on Jetson Nano port 5000. Family members access cara.local:5000/video_feed from any phone browser on the local network — no app required.

🕹️
High

Remote Drive (Phone Browser)

HTTP POST endpoint receives directional commands from a phone web interface. Motor commands are forwarded to Arduino via serial — but obstacle avoidance always takes precedence, regardless of remote command.

🌡️
High

Temperature Monitoring & Alert

DHT22 sensor monitors room temperature. If ambient temperature exceeds 38°C for more than 5 minutes, CARA triggers a heatstroke-risk SMS alert and activates the LCD warning message.

🔋
High

Battery Management

Voltage divider monitors LiPo cell voltage. Below 10.5V (≈25% capacity), LED shifts to blue and LCD displays low battery warning. Below 9.6V (≈5%), non-critical motors are suspended and a battery SMS alert is sent.

📅
High

Daily Check-In SMS

At 12:00 noon each day, the health_management ROS node sends a status SMS confirming that CARA is online and the user was seen in the past 4 hours. Families receive silence-is-an-alert assurance.

🎙️
High

Greeting & LCD Messages

When person presence is detected via PIR sensor, CARA displays a warm greeting on the 16×2 I2C LCD and activates a short audible chime. Messages rotate between time-appropriate greetings based on RTC hour.

Medium Priority

These features enhance the interaction quality and data collection capabilities. They will be implemented if the core tiers are stable within the 12-week timeline.

💡
Medium

LED State Feedback

Three RGB LEDs provide continuous visual status: green (IDLE), slow-amber pulse (ACTIVE following), blue pulse (MONITORING), solid red (ALERT), rapid amber (low battery). Colour coding is intuitive without needing documentation.

🔻
Medium

Cliff / Stair Detection

Three TCRT5000 infrared sensors mounted facing downward detect floor edge loss (staircase or dropped surface). Emergency stop is triggered if two or more sensors simultaneously lose floor reflection.

📸
Medium

Pan-Tilt Camera Head

Two SG90 servo motors provide pan (left-right, Pin 9) and tilt (up-down, Pin 10, default 75°) control. Pan angle is derived from nose X position in the MediaPipe frame — CARA keeps the user centred in the camera view.

Feature Implementation Status

Features are being implemented sequentially from Critical → High → Medium throughout Weeks 3–8 of the project. Current implementation status is logged in the Development Blog.
