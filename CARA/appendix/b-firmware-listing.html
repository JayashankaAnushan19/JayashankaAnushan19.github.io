Appendix B Confirmed

Firmware Listing

Arduino Mega 2560 firmware — the real-time controller for every peripheral: motors, ultrasonic ring, GSM, LCD, keypad, buzzer, and the escalating alert/reminder system.

Rather than embedding a snapshot of the code here — which inevitably drifts out of date the moment the firmware changes, as the previous version of this page did — this appendix links directly to the live file in the project's GitHub repository. It's always the current version, with full commit history.

cara_main_mega_gsm.ino

The current main firmware — a 5-state machine (IDLE, ACTIVE, MONITORING, ALERT, RESET) built on non-blocking millis() timing, with GSM alerting on the A7670C, keypad-based acknowledgement (RFID acknowledgement was tried and removed after a power-quality fault — see Blog Week 16), the obstacle-fusion drive logic, and the escalating fall/medication alert system.
