Fall Detection Node

The real fall-detection pipeline: a trained RandomForestClassifier scoring MediaPipe pose landmarks, wrapped in a ROS2 node.

An earlier version of this page was an autogenerated placeholder skeleton, not real code. It's since been replaced with direct links to the two real files in the project's GitHub repository, so this page can never drift out of sync with the actual implementation.

fall_detection_node.py

The ROS2 node — subscribes to person_tracker_node's lock state (FACE/BAND/LOST) and only runs pose detection while actively tracking the enrolled patient, publishing FALL_DETECTED straight to /cara/drive_cmd on a confirmed fall.

View on GitHub →

fall_detection.py

The core classifier logic that the node wraps — MediaPipe Pose extraction (33 landmarks → 69 derived features), the trained RandomForestClassifier, and the two-layer confirmation (0.35 entry threshold, then 3 consecutive rising-angle/hip checks over ~2.7s).
