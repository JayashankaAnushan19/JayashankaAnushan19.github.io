10–16 Jul 2026 Week 05 Hardware Milestone

Milestone M3 Reached — Hardware Ready, Jetson Nano In Hand and ROS Setup Begins

Chassis, motors, and sensors are integrated and running on the Arduino Mega state machine — hitting Milestone M3 (Hardware Ready) on schedule. The Jetson Nano is in hand and ROS Jazzy setup has started on it. The SIM7600 4G module is still awaiting delivery, so GSM wiring hasn't started yet — that stays queued for as soon as it arrives.

Short-form update: this post captures where the build stands as Week 05 closes. Photos and the detailed step-by-step notes from the field book are still being transcribed and will be added here shortly — the checklist below reflects the real status either way.

Milestone M3 — Hardware Ready

The components staged together at the end of Week 04 — chassis, Arduino Mega, HC-SR04, PIR, LCD, RTC — are now wired and mounted rather than just laid out for a fit check. The 5-state machine (Idle / Active / Monitoring / Alert / Reset) designed back in Week 02 and first proven on the DIY kit in Week 03 is now running on the real chassis and motor setup, with the LCD reflecting live state changes.

This closes Milestone M3 as planned in the project timeline: chassis assembled, motors working, sensors integrated, state machine running.

SIM7600 (4G/LTE) — Still Awaiting Delivery

The SIM7600 module and the 1000µF buffer capacitor ordered at the end of Week 04 (to replace the SIM800L, which turned out to be a dead end since 2G is decommissioned in the UAE) haven't arrived yet. GSM wiring and the AT-command bring-up can't start until they do, so that work is pushed to whichever week the delivery lands in.

Per the project plan this task runs through Week 07, so there's still runway — but it's now the main blocker on the alerting side of the build.

ROS Jazzy Setup on Jetson Nano — Started

With the SD card sorted, setup work on the Jetson itself began this week — flashing the board image and starting the ROS Jazzy install, the software foundation the Week 02 architecture design calls for on the AI side of the dual-controller split (Jetson for AI/vision, Arduino for real-time peripherals). This groundwork is what the MediaPipe port depends on next.

Note on the board itself: the design and documentation target an NVIDIA Jetson Nano 4GB, which is enough compute for this project's fall-detection and ROS workload. Due to availability, the actual unit in hand for this build is a Jetson Orin Nano 8GB Developer Kit instead — a straightforward drop-in swap that doesn't change any of the architecture or wiring described elsewhere on this site.

MediaPipe Fall Detection — Still Continuing on Laptop

The fall-detection pipeline validated on laptop in Week 04 (60.6% confidence on a test video, full Arduino serial handshake into the Alert state) hasn't moved onto the Jetson yet — that migration depends on the ROS Jazzy setup above being finished first. Laptop remains the development environment for now; this task is planned to run through Week 06.

What Did Not Go Well

The SIM7600 order hasn't landed yet, which stalls the GSM alerting track — it's now the critical-path item since AT-command bring-up, SMS testing, and wiring it into the Alert state all depend on it. Full write-up for the hardware and Jetson work is also still catching up to the actual bench work — the field book has more detail than made it into this draft, and will be filled in as a follow-up pass.
