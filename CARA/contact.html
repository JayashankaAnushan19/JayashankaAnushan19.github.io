About the Project

CARA (Companion Assistive Robot for the Aged) is an MSc Robotics thesis project focused on building a low-cost, GSM-based assistive robot for elderly care in developing countries — specifically Sri Lanka.

The project runs from May–July 2026. This documentary site tracks every stage of the build.
