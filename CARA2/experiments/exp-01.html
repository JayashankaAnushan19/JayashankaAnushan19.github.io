EXP-01Registered 8 October 2026

What firmware and software is actually running on the robot, and does the repository reproduce it exactly?

Why this matters

Every V2.0 experiment changes something and measures the effect. That only means something if the starting point is known exactly. The V1 audit found signs that the code in the repository and the code on the robot have drifted apart.

Evidence so far

  • Dashboard comments dated 6 Oct 2026 refer to a firmware software-clock fallback and an encoder PI stall guard (MOTOR: lines) that do not exist in the repository firmware cara_main_mega_gsm.ino.
  • The firmware header lists LED = pin 10 / servo = pin 46; the 29 Sep 2026 log records the servo physically moved to pin 10.
  • The RTC reported “not detected” on 6 Oct 2026, after being confirmed working on 29 Sep 2026.

Planned method

  • Probe the flashed firmware (boot banner, command responses) and compare its behaviour with the repository source.
  • Continuity-test every connector and publish a verified pin map on the Hardware page.
  • Tag a reproducible V2 baseline commit once robot and repository agree.

Measures

  • Number of discrepancies found and resolved
  • Verified pin map (yes/no per pin)
