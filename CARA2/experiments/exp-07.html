Secure remote access over low-cost links

EXP-07Registered 8 October 2026

Can family abroad reach the robot securely without port forwarding, a fixed IP, or a paid service?

Why this matters

The second user of CARA is the adult child abroad. Today the dashboard works only on the home network.

Evidence so far

  • The dashboard already has a password login, but the password is stored in plain text and the session key regenerates on every restart.
  • Plan agreed 13 Sep 2026: free ngrok tunnel, SMS to family whenever the link changes, family number editable and stored in the Mega’s EEPROM — not yet built.

Planned method

  • Implement the tunnel, hashed credentials, and SMS-on-link-change.
  • Multi-day soak test on home broadband.

Measures

  • Link availability
  • Time to notify on link change
  • Authentication failures

Status history

  • 8 October 2026 — Registered as proposed.
