Journal

Formal entries, written when an experiment produces a result worth stating — including negative ones. Each entry follows a standard research-paper structure and can be printed or saved as PDF in journal format.

Entry types

TypeUsed for
Research ArticleA complete experiment: question, method, results, discussion.
Technical ReportSystem descriptions, baselines, design decisions with measured justification.
Short CommunicationA single clear finding that doesn’t need a full article.
Negative ResultAn approach that did not work, with enough detail that nobody needs to repeat it.
Method NoteA reusable test procedure, tool or protocol.
